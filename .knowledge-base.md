# DNA-Lang Knowledge Base

## Consolidated Reference for 7 DNA Data Types + Synthesis Language

### Cross-Cutting Framework

DNA is an information system with **typed functional categories**. Each biological sequence class maps to a programming language construct:

| DNA Type | Biological Role | PL Construct | Haskell Analogy |
|----------|----------------|--------------|-----------------|
| Coding Sequences | Protein synthesis | Executable functions | `data ProteinCode a` with `transcribe`/`translate` |
| Regulatory Sequences | Gene expression control | Control flow / scheduling | `data Regulator a` with `ExpressionLevel` |
| Non-Coding RNAs | Post-transcriptional regulation | Signals / interrupts / middleware | `data RNAControl p` with `silence`/`scaffold` |
| Structural DNA | Chromosome integrity | Memory layout / protection | `data Structure g` with `Telomere`/`Centromere` |
| Repetitive Elements | Genome plasticity | Self-modifying code / macros | `data Repeat s` with `transpose`/`copy` |
| Epigenetic Marks | Accessibility state | Runtime config / permissions | `data State a` with `Methylation`/`Histone` |
| Developmental Programs | Organism development | Orchestrators / factories | `data Program d` with `differentiate`/`pattern` |

## Type 1: Coding Sequences — ProteinCode<T>

### Biology
- **Central Dogma**: DNA → mRNA (transcription) → Protein (translation)
- **Codons**: Triplets of nucleotides, 64 codons → 20 amino acids + stop signals
- **Reading frames**: 3 possible frames per strand, 6 total per double-stranded DNA
- **Alternative splicing**: One gene → multiple mRNA variants → multiple protein isoforms
- **Post-translational modification**: Phosphorylation, glycosylation, ubiquitination change protein function
- **Mutations**: Silent (synonymous), missense (amino acid change), nonsense (premature stop), frameshift

### PL Parallel
- DNA → mRNA → Protein = Source code → Intermediate Representation → Machine code
- Codon table = Opcode mapping (instruction set architecture)
- Reading frames = Parser alignment / lexer state
- Alternative splicing = Conditional compilation / template metaprogramming
- Mutations: Silent = refactoring, Missense = type-compatible change, Nonsense = type error, Frameshift = parse error
- Post-translational modification = Runtime monkey-patching / decorator pattern

### Key Theorems to Develop
1. **Compilation Correspondence**: The central dogma is a typed compilation pipeline with type preservation guarantees
2. **Codon Redundancy as Error Correction**: Synonymous codons implement a Hamming-distance-like error correction at the type level
3. **Splicing as Dependent Types**: Alternative splicing produces context-dependent types, formalizable as dependent type families

## Type 2: Regulatory Sequences — Regulator<ExpressionLevel>

### Biology
- **Promoters**: DNA regions upstream of genes where RNA polymerase binds; determine transcription initiation
- **Enhancers**: Distal regulatory elements that increase transcription (can be thousands of bp away)
- **Silencers**: Repress transcription
- **Insulators**: Block enhancer-promoter communication across boundaries
- **Transcription factors**: Proteins that bind regulatory sequences to activate/repress
- **Gene regulatory networks (GRNs)**: Directed graphs of regulatory interactions
- **Feedback loops**: Positive (switch-like) and negative (homeostatic) circuits

### PL Parallel
- Promoter = Function entry point / calling convention with expression level parameter
- Enhancer = Environment variable / remote configuration that amplifies behavior
- Silencer = Access control / `private` modifier / firewall rule
- Insulator = Module boundary / namespace isolation
- Transcription factor = First-class function / callback / event handler
- GRN = Dataflow graph / reactive programming dependency graph
- Feedback loops = Recursive control flow / event loops

### Key Theorems
1. **Regulatory Completeness**: Promoter + enhancer + silencer + insulator form a complete control flow algebra
2. **GRN as Category**: Gene regulatory networks form a category with composition of regulatory effects
3. **Bistability as Boolean**: Positive feedback loops implement boolean switching, formalized as fixed-point computation

## Type 3: Non-Coding RNAs — RNAControl<Process>

### Biology
- **miRNA** (microRNA): ~22nt, binds mRNA 3'UTR, represses translation or promotes degradation
- **siRNA** (small interfering RNA): ~21nt, RNA interference pathway, degrades complementary mRNA
- **lncRNA** (long non-coding RNA): >200nt, scaffolds, guides, decoys for regulatory complexes
- **tRNA** (transfer RNA): Adaptor between mRNA codons and amino acids
- **rRNA** (ribosomal RNA): Structural + catalytic component of ribosome
- **snRNA** (small nuclear RNA): Spliceosome components, pre-mRNA splicing
- **piRNA** (piwi-interacting RNA): Transposon silencing in germline

### PL Parallel
- miRNA = Runtime assertion / guard clause (post-transcriptional quality check)
- siRNA = Exception handler / kill signal (targeted mRNA destruction = RNAi)
- lncRNA = Middleware / scaffold (assembles regulatory complexes)
- tRNA = Type adapter / codec (converts between codon and amino acid "types")
- rRNA = Virtual machine / runtime engine (the ribosome IS the execution platform)
- snRNA = Preprocessor / macro expander (splicing = compile-time code transformation)
- piRNA = Security monitor / anti-malware (silences transposon "malicious code")

### Key Theorems
1. **RNAi as Exception Handling**: The RISC complex implements a typed exception handler with sequence-complementarity as pattern matching
2. **tRNA as Natural Transformation**: tRNA adaptor function is a natural transformation between the codon functor and the amino acid functor
3. **lncRNA Scaffold Theorem**: lncRNA-mediated complex assembly is a colimit in the category of molecular interactions

## Type 4: Structural DNA — Structure<GenomeLayout>

### Biology
- **Telomeres**: TTAGGG repeats at chromosome ends, prevent degradation, shorten with cell division
- **Centromeres**: Specialized chromatin for kinetochore assembly, essential for chromosome segregation
- **TADs** (Topologically Associating Domains): Self-interacting chromatin domains (100kb-1Mb)
- **Lamina-Associated Domains (LADs)**: Chromatin tethered to nuclear envelope, generally repressive
- **Chromatin loops**: Cohesin/CTCF-mediated loops bringing distal elements together
- **Nuclear organization**: Chromosome territories, nuclear bodies, phase separation

### PL Parallel
- Telomere = Buffer overflow protection / lifetime counter (Hayflick limit = maximum stack depth)
- Centromere = Process synchronization primitive / mutex (ensures correct chromosome distribution)
- TAD = Memory segment / address space partition
- LAD = Swap space / cold storage (repressed regions parked at periphery)
- Chromatin loop = Pointer / reference (brings distant genomic "addresses" into proximity)
- Nuclear organization = Memory hierarchy (L1/L2/L3 cache, RAM, disk)

### Key Theorems
1. **Telomere as Linear Resource**: Telomere shortening implements linear type consumption — each division "uses" a resource that cannot be duplicated
2. **TAD Encapsulation**: TADs form a natural encapsulation boundary formalizable as a sheaf condition on the chromatin topology
3. **Chromosome Territory as Memory Protection**: Each territory is an independent address space with controlled inter-territory communication

## Type 5: Repetitive Elements — Repeat<SelfModifying>

### Biology
- **DNA transposons**: "Cut and paste" — excise from one location, insert at another
- **Retrotransposons**: "Copy and paste" — transcribe to RNA, reverse-transcribe, insert copy
  - **LINEs** (Long Interspersed Nuclear Elements): Autonomous, encode reverse transcriptase (L1 = ~17% of human genome)
  - **SINEs** (Short Interspersed Nuclear Elements): Non-autonomous, depend on LINE machinery (Alu = ~11%)
- **Satellite DNA**: Tandem repeats at centromeres and telomeres
- **Endogenous retroviruses (ERVs)**: ~8% of human genome, mostly inactivated
- **Transposon domestication**: Co-opted for host functions (V(D)J recombination, placental syncytins)

### PL Parallel
- DNA transposon = `cut` + `paste` refactoring operation / move semantics
- Retrotransposon = `copy` + `paste` code duplication / template instantiation
- LINE = Autonomous macro with self-contained expansion machinery
- SINE = Dependent macro requiring external expander (LINE machinery)
- Satellite DNA = Memory alignment / padding / struct layout optimization
- ERV = Legacy library import (dormant but structurally present)
- Domestication = Library adoption (foreign code integrated into core functionality)

### Key Theorems
1. **Transposon as Functor**: Transposition is an endofunctor on the genome category that preserves or modifies local structure
2. **Self-Modification Paradox**: Self-modifying genomes face a Gödelian limitation: no transposon can predict its own insertion site
3. **Domestication as Naturalization**: Transposon domestication is a natural transformation from the "foreign code" functor to the "host function" functor

## Type 6: Epigenetic Marks — State<Accessibility>

### Biology
- **DNA methylation**: 5-methylcytosine at CpG dinucleotides, generally repressive
- **Histone modifications**: Acetylation (open), methylation (context-dependent), phosphorylation, ubiquitination
  - H3K4me3 = active promoter
  - H3K27me3 = Polycomb repression
  - H3K9me3 = heterochromatin
  - H3K27ac = active enhancer
- **Chromatin remodeling**: ATP-dependent remodelers (SWI/SNF, ISWI, CHD, INO80)
- **Epigenetic inheritance**: Maintenance methyltransferase (DNMT1) copies methylation pattern to daughter strand
- **CpG islands**: Clusters of CpG sites, often at promoters, usually unmethylated in active genes
- **Bivalent chromatin**: H3K4me3 + H3K27me3 simultaneously (poised state in stem cells)

### PL Parallel
- DNA methylation = Persistent configuration flag / `.env` file / registry key
- H3K4me3 = `chmod +x` (marks as executable/active)
- H3K27me3 = `chmod -r` (marks as unreadable/repressed)
- H3K27ac = `public` access modifier
- Chromatin remodeling = Garbage collection / memory defragmentation
- Epigenetic inheritance = State serialization / process checkpointing across restarts
- Bivalent chromatin = Quantum superposition of active/inactive (Schrödinger's gene)

### Key Theorems
1. **Epigenetic State Machine**: The histone modification landscape forms a finite state machine with transitions governed by writer/eraser enzymes
2. **Methylation as Monad**: CpG methylation forms a monad on the gene expression functor: `return` = unmethylated, `bind` = methylation-dependent expression
3. **Bivalency as Superposition**: Bivalent chromatin is a product type `(Active, Repressed)` that resolves to a sum type `Active | Repressed` upon differentiation signal

## Type 7: Developmental Programs — Program<OrganismDevelopment>

### Biology
- **Hox genes**: Clustered transcription factors specifying body segment identity along anterior-posterior axis
- **Morphogen gradients**: Concentration-dependent signaling (Wnt, Hedgehog, BMP, FGF, Notch)
- **Cell fate specification**: Competence → specification → determination → differentiation
- **Regulatory cascades**: Master regulators activate subordinate transcription factors
- **Apoptosis**: Programmed cell death via intrinsic (mitochondrial) or extrinsic (death receptor) pathways
- **Stem cells**: Self-renewal + multipotent differentiation capacity
- **Organogenesis**: Coordinated tissue formation through inductive signaling

### PL Parallel
- Hox genes = Main orchestration module / deployment descriptor specifying component identity
- Morphogen gradient = Distributed configuration server / service mesh (concentration = priority/weight)
- Cell fate = Process specialization / worker pool assignment
- Regulatory cascade = Initialization sequence / boot loader chain
- Apoptosis = Graceful shutdown / `kill -SIGTERM` / garbage collection of processes
- Stem cells = Factory pattern / abstract base class / polymorphic constructor
- Organogenesis = Container orchestration (Kubernetes-like tissue assembly)

### Key Theorems
1. **Waddington Landscape as Type Refinement**: Cell differentiation paths correspond to refinement type narrowing — each step reduces the type from `StemCell` to increasingly specific cell types
2. **Morphogen Gradient as Dependent Type**: Positional information creates spatially-dependent types: `CellFate(position, concentration)`
3. **Hox Collinearity as Program Order**: Hox gene spatial/temporal collinearity is a monotone functor from chromosome position to body axis position
